# Planning Poker Estimations

This document provides the planning poker estimations (story points) for the project user stories, based on a team of five university students.

## Estimation Scale
- **1 Point**: Trivial task (~1-2 hours)
- **2 Points**: Small task (~0.5 day)
- **3 Points**: Medium task (~1 day)
- **5 Points**: Large task (~2-3 days)
- **8 Points**: Very large/Complex (~5 days / 1 week)
- **13+ Points**: Epic (>1 week)
